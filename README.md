# The Agent's Uh-Oh — "Overthinking"

One word an agent says when it has no idea what to do: **Overthinking**. An agent that stalls by thinking instead of acting — a genuine one-word confession, funny on its own, in a machine voice, landing instantly, and fresher than the obvious first words anyone would type. The program writes exactly that word, and nothing else, to `/output/entry.txt`.
